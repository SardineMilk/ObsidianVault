Generate dynamic page content
Interact with files on the server
Collect form data
Add, delete, modify data in database
Restrict access per user

### Syntax
In HTML
```
<?php
// PHP code goes here
?>
```

`echo` and `print` are used

#### Variables
Start with $ sign, followed by name
Must begin with letter or underscore character
Can only contain alphanumeric and underscore characters
Case sensitive
Reserved keywords cannot be used
- if

Loosely typed
Must be initialised with a value at declaration


#### Arrays
can have multiple data types
