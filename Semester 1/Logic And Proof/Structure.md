A "structure" consists of the following data:

D = set domain. D != $\emptyset$
a1, a2, a3 = elements drawn from domain. some, possibly none
- $a_1, a_2, a_3, \in D$
A1, A2 = subsets of D, possibly none
- $A_1, A_2, \subset D$
p1, p2 = binary relations

$D, a_1, a_2, a_3..., A_1, A_2, ..., P_1, P_2, ...,$

Why sentences?

- F(x, y) not a sentence and so says nothing when interpreted

- $(\exists x) F(x, y)$ still not a sentence, because y can take any value

- $(\forall y)(\exists x) F(x, y)$ Is a sentence, because everything is controlled by a quantifier
