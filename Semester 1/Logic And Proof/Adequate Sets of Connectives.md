> We say that a set of [[Logical Connectives|connectives]] is adequate if every [[Well-Formed Formulae|wff]] is logically equivalent to a wff that uses only the connectives from that set.

[[Logic-book.pdf#page=55&selection=11,46,17,30|Logic-book, page 55]]

$\neg$ and ($\land$ or $\lor$) are adequate
therefore, to prove a set of connectives is adequate, show it can construct these connectives
