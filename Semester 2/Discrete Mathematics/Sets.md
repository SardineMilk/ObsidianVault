"|" means "such that"

**Set** - an unordered collection of objects
- $A = \{1, 2, 3\}$

**Subset** - set $B$ is a subset of set $A$ if every element of $B$ is also an element of $A$
- $B = \{1, 3\}$
- $B \subset A$

**Ordered Pair** - a pair $(a, b)$ where $a$ comes before $b$

**Cartesian Product** - $A \bigtimes B$ , the set of all ordered pairs $(a, b)$ where $a \in A$ and $b \in B$
- $A = \{1, 2, 3\}, B= \{x, y\}$
- $A \bigtimes B = \{(1, x), (1, y), (2, x), (2, y), (3, x), (3, y)\}$
- This is a [[Set Operations|set operation]], defined as:
	- $A \bigtimes B := \{(a, b)|a \in A, b \in B \}$
