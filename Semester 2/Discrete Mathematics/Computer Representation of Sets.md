Store universal [[Semester 1/Logic And Proof/Sets|set]] $U$ as an ordered list
Represent subset $A$ as by a *bit string*

#### Example
$U = \{1, 2, 3, 4, 5, 6\}$
$A = \{2, 4, 6\}$
$B = \{2, 3, 5\}$

Bit strings:
A = 010101
B = 011010

This allows bit-wise operations to be done for [[Set Operations|set operations]]
