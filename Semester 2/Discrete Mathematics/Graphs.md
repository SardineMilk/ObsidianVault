
G = (V, E)

Vertices
- Set
Edges 
- List of pairs of vertices

$V = \{a, b, c, d\}$
$E = \{a, b\}, \{a, c\}, \{c, d\}, \{b, d\}$

Simple Graphs
- No repeated (multiple) edges
- No loops ($\{a, a\}$)

Subgraphs
- Remove some vertices
- Remove some edges
- Cannot remove endpoints of remaining edges
	- Each edge must have 2 vertices



You can represent a graph using an [[Adjacency Matrix]]
